# JS Mini Games

JavaScript の主要な考え方を、短いゲームを作りながら学ぶための教材です。

フレームワークやビルドツールは使いません。ブラウザとテキストエディタだけで、HTML / CSS / JavaScript の動きをそのまま追えます。

未経験からフロントエンドを目指す過程で、基礎を定着させるために作成した教材です。

ゲーム一覧はこちら → https://sakamoto-08.github.io/js-mini-games/

## フォルダ構成

```text
js-mini-games/
├── README.md              このファイル。全体の案内
├── common/                ゲームをまたいで使う部品
│   ├── common.css         共通の見た目（レイアウト、ボタン、メッセージ）
│   └── common.js          共通の関数（乱数、スコア、メッセージ、リスタート、タイマー）
└── games/                 ゲーム1つにつき1フォルダ
    ├── 01-number-guess/   数当て（index.html, style.css, script.js, README.md）
    ├── 02-janken/         じゃんけん（同じ4ファイル）
    ├── 03-click-counter/  クリックカウンター（同じ4ファイル）
    ├── 04-reaction-time/  反応速度（同じ4ファイル）
    ├── 05-whack-a-mole/   モグラ叩き（同じ4ファイル）
    ├── 06-dice-battle/    サイコロ勝負（同じ4ファイル）
    ├── 07-typing/         タイピング（同じ4ファイル）
    ├── 08-memory/         神経衰弱（同じ4ファイル）
    ├── 09-stopwatch/      ストップウォッチ（同じ4ファイル）
    ├── 10-quiz/           クイズ（同じ4ファイル）
    ├── 11-snake/          スネーク簡易版（同じ4ファイル）
    ├── 12-breakout/       ブロック崩し簡易版（同じ4ファイル）
    ├── 13-pong/           ポン簡易版（同じ4ファイル）
    ├── 14-flappy/         フラッピーバード簡易版（同じ4ファイル）
    ├── 15-invaders/       インベーダー簡易版（同じ4ファイル）
    ├── 16-minesweeper/    マインスイーパー簡易版（同じ4ファイル）
    ├── 17-rpg/            簡易RPG（同じ4ファイル）
    └── 18-catch/          キャッチゲーム（同じ4ファイル）
```

`common` は「どのゲームでも要る処理」をまとめる場所です。各ゲームは相対パス（`../../common/common.js`）でこれを読み、ゲーム固有のルールだけを自分の `script.js` に書きます。

## 学習の進め方

1. `games/01-number-guess/index.html` をブラウザで開いて遊ぶ。
2. 同じフォルダの `README.md` で、そのゲームが扱う概念を確認する。
3. `script.js` を上から読み、コメントと処理を対応させる。
4. 数字の範囲を変える、メッセージの文言を変える、など小さく改造してみる。
5. 次の番号のゲームへ進む。

ファイルを直接開いても動きます。変更が反映されないときは、ブラウザを再読み込みしてください。

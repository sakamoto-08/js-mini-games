# 14 フラッピーバード

スペースかクリックでキャラクターをジャンプさせ、流れてくるパイプの隙間をくぐります。くぐるたびにスコアが 1 増えます。パイプ、地面、天井のどれかに当たるとゲームオーバーです。最高記録はブラウザに保存されるので、ページを再読み込みしても残ります。

## このゲームで学ぶ概念

- **重力** … 毎フレーム `birdVy` に `GRAVITY` を足します。速度がプラスだと下へ進みます。ジャンプは速度をマイナス（上向き）に入れ替えるだけです。
- **スクロール** … キャラクターの横位置は固定です。パイプの `x` を毎フレーム減らすと、障害物が左へ流れて見えます。画面の外に出たパイプは配列から消します。
- **矩形の衝突** … キャラクター、パイプ、地面、天井をすべて四角として持ち、辺が重なるかを `rectsOverlap` で調べます。
- **状態** … `gameState` が `"ready"` のあいだは重力もスクロールも止めます。`"playing"` で動き、`"finished"` で止まります。
- **配列** … パイプは `{ x, gapY, passed }` の配列です。`passed` が false のパイプをくぐったときだけ得点にします。
- **関数の再利用** … スコア、最高記録、結果メッセージ、もう一度ボタン、隙間の高さの乱数は `common.js` に任せます。最高記録の読み書きは `getHighScore` と `updateHighScore` です。
- **localStorage** … ゲームオーバーのとき、今回の得点が保存済みの記録より大きいときだけ書き込みます。キーは `js-mini-games-flappy-highscore` です。

## 遊び方

1. `index.html` をブラウザで開く。キャラクターは止まった状態です。
2. スペースか、盤面のクリックでジャンプします。最初のジャンプでゲームが始まります。
3. 何もしないと重力で落ちます。キーを押し続けても、押し始めの 1 回だけ跳ねます。
4. 緑のパイプの隙間をくぐるとスコアが 1 増えます。
5. パイプ、上の帯、下の帯に触れるとゲームオーバーです。得点がこれまでの最高より大きいときだけ、最高記録が更新され、「最高記録です！」と出ます。
6. 「もう一度」でスコアとパイプが最初に戻ります。最高記録は残ります。ページを再読み込みしても、最高記録は残っています。

## ファイルの役割

| ファイル | 役割 |
| --- | --- |
| `index.html` | 見出し、スコアの置き場、Canvas、メッセージ。「もう一度」の置き場。`common.css` / `common.js` を相対パスで読み込む。 |
| `style.css` | スコアの 2 列、縦長の盤面を中央に置く大きさ。 |
| `script.js` | 重力、ジャンプ、パイプの流れ、四角の衝突、最高記録。 |
| `../../common/common.js` | `getRandomInt`、`createScoreDisplay`、`updateScore`、`showMessage`、`clearMessage`、`createRestartButton`、`getHighScore`、`updateHighScore`。 |
| `../../common/common.css` | 暗い背景、スコア、メッセージ、ボタン。 |

## 読んでみる順番

1. `moveBird` で、重力が速度になり、速度が位置になる流れを見る。
2. `flap` で、ジャンプが「上向きの速度を入れ直す」だけだと確認する。
3. `movePipes` と `ensurePipes` で、パイプが左へ動き、右に追加される箇所を追う。
4. `rectsOverlap` と `hitObstacle` で、どの四角どうしを比べているかを見る。
5. `finishGame` で、`updateHighScore` が記録を超えたときだけ保存している箇所を確認する。

小さく改造するなら、`GAP_HEIGHT` を `140` に変えてみてください。パイプの隙間が広くなります。

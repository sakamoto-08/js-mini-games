# 12 ブロック崩し

下のバーでボールを跳ね返し、上のブロックを壊します。1個壊すとスコアが 1 増えます。ボールが下に落ちるとゲームオーバー、全部壊すとクリアです。「もう一度」でやり直せます。最高記録は、ページを再読み込みするまで残ります。

## このゲームで学ぶ概念

- **Canvas** … `getContext("2d")` で描画口を取ります。ブロックとバーは `fillRect`、ボールは `arc` で描きます。毎フレーム、背景を消してから描き直します。
- **アニメーション** … `requestAnimationFrame` が、次の画面更新で `loop` を呼びます。蛇は一定時間ごとに1マス進みますが、ボールは毎フレーム少しずつ動かします。前回からの秒数を速度に掛けるので、フレームが揺れても速さはほぼ一定です。
- **なぜ `createTimer` を使わないか** … `createTimer` は 1 秒ごとにしか進みません。ボールの移動と描画は、それより細かい間隔で画面に合わせたいので `requestAnimationFrame` を使います。
- **衝突** … 円の中心に一番近い長方形上の点を探し、その距離が半径以下なら当たったとみなします。壁は座標がはみ出したかで判定します。
- **操作** … 左右は `keydown` と `keyup` で押し続けを覚えます。マウスやタッチは `pointermove` で、表示上の位置を Canvas の座標に変換します。発射はスペースとクリックです。
- **状態** … `gameState` が `"ready"` のあいだボールはバーの上で待ち、`"playing"` で動き、`"finished"` で止まります。
- **2次元配列** … `blocks[行][列]` が `true` なら、そのブロックは残っています。壊すときは `false` にします。
- **関数の再利用** … スコア、最高記録、結果メッセージ、もう一度ボタン、発射角度の乱数は `common.js` に任せます。

## 遊び方

1. `index.html` をブラウザで開く。ボールはバーの上で止まっています。
2. 左右の矢印キーか A / D、または盤面の上でマウスを動かしてバーを動かします。
3. スペースか、盤面のクリックでボールを出します。真上から少しだけ左右にずれます。
4. ブロックに当たるとそのブロックが消え、スコアが 1 増えます。バーの端で返すほど、ボールは横に飛びます。
5. 下に落ちるとゲームオーバーです。全部壊すとクリアです。
6. 「もう一度」でブロックとスコアが最初に戻ります。最高記録は残ります。

## 読んでみる順番

1. `createBlocks` と `blockRect` で、2次元配列とマスの位置の関係を見る。
2. `draw` で、`fillRect` と `arc` が何を塗っているかを追う。
3. `loop` で、`requestAnimationFrame` と「前回からの秒数」の使い方を確認する。
4. `circleHitsRect` と `moveBall` で、壁・バー・ブロックの判定がどの順かを見る。

小さく改造するなら、`BALL_SPEED` を `160` に変えてみてください。ボールがゆっくりになります。

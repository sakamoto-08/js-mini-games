# 09 ストップウォッチ

「スタート」で計測を始め、「ストップ」で止めます。止めたあとにスタートを押すと、0 からではなく続きから測ります。「ラップ」で途中の時間を一覧に残せます。「リセット」で時間とラップを 0 に戻します。

## このゲームで学ぶ概念

- **経過時間** … `performance.now()` はページを開いてからのミリ秒です。スタート時刻との差が、いまの経過時間になります。
- **表示の更新** … `setInterval` で 10 ミリ秒ごとに画面の文字を書き換えます。止めるときは `clearInterval` で止めます。
- **なぜ `createTimer` を使わないか** … `createTimer` は 1 秒ごとにしか進みません。1/100 秒まで出すには、自分で `setInterval` と `performance.now()` を組み合わせます。
- **表示の形** … ミリ秒を分・秒・1/100秒に分け、それぞれ 2 桁にして `00:01.23` のようにつなぎます。
- **状態** … `watchState` が `"running"` のときだけ時間が増えます。止めた時間は `elapsedMs` に確定してから、次のスタートで足します。
- **ボタン** … 計測中はスタートを無効にし、止まっているときはストップとラップを無効にします。`disabled` のボタンはクリックできません。
- **配列** … ラップは配列にミリ秒を追加し、一覧を描き直します。
- **関数の再利用** … ラップ数、一時停止のメッセージ、リセットボタンは `common.js` に任せます。

## 遊び方

1. `index.html` をブラウザで開く。表示は `00:00.00` です。
2. 「スタート」を押す。時間が進み、スタートは押せなくなります。
3. 「ラップ」を押すと、その時点の時間が下の一覧に残ります。計測は続きます。
4. 「ストップ」を押すと時間が止まり、「一時停止中」と出ます。
5. もう一度「スタート」を押すと、止めたところから続きます。
6. 「リセット」で `00:00.00` に戻り、ラップも消えます。時間もラップも無いときは押せません。

## ファイルの役割

| ファイル | 役割 |
| --- | --- |
| `index.html` | 見出し、時間表示、ボタン、メッセージ、ラップ一覧。`common.css` / `common.js` を相対パスで読み込む。 |
| `style.css` | 大きな時間、2列のボタン、ラップ一覧。 |
| `script.js` | 経過時間の計算、表示の形、スタート・ストップ・ラップ・リセット、ボタンの有効と無効。 |
| `../../common/common.js` | `createScoreDisplay`、`updateScore`、`showMessage`、`clearMessage`、`createRestartButton`。 |
| `../../common/common.css` | 画面中央のレイアウト、暗い背景、スコア、メッセージ、ボタン。 |

## 読んでみる順番

1. `getElapsedMs` で、止まっているときと計測中で足し方がどう違うかを見る。
2. `formatTime` で、ミリ秒が `00:01.23` になるまでの計算を追う。
3. `startWatch` と `stopWatch` で、`setInterval` を始めて止める場所を確認する。
4. `updateButtons` で、状態ごとにどのボタンが無効になるかを見る。

小さく改造するなら、`TICK_MS` を `100` に変えてみてください。表示の更新がゆっくりになります。

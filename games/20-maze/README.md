# 20 迷路

矢印キーか WASD で通路を進み、右下の緑のマスを目指します。迷路は開くたびに穴掘り法で作り直すので、スタートからゴールまで必ず道があります。壁には入れません。「もう一度」で新しい迷路になります。最短手数とクリア回数はブラウザに保存されるので、ページを再読み込みしても残ります。

## このゲームで学ぶ概念

- **2次元配列** … 盤面は `board[行][列]` です。`"wall"` が壁、`"path"` が通路です。
- **穴掘り法** … 最初は全部壁です。今のマスから2マス先がまだ壁なら、あいだの壁を崩して進みます。四方をランダムな順で試します。
- **再帰** … `carve` は、進んだ先で自分をもう一度呼びます。進める先が無くなったらその呼び出しが終わり、1つ前の分かれ道に戻ります。スタートから届くマスはすべて掘るので、ゴールが孤立しません。
- **状態** … プレイヤーの位置は `{ x, y }` です。`gameState` は最初の一手の前が `"ready"`、移動中が `"playing"`、ゴールで `"finished"` です。
- **キーボード** … `keydown` で押されたキーを上下左右に変えます。矢印キーでは `preventDefault` して、ページがスクロールしないようにします。
- **ゴール判定** … 移動したあとの位置がゴールの座標と同じならクリアです。壁のマスへは移動そのものをしません。
- **関数の再利用** … 手数の表示、結果メッセージ、もう一度ボタン、掘る方向の乱数、記録の保存は `common.js` に任せます。
- **localStorage** … 最短手数は小さい方が良いので、今より少ないときだけ `setHighScore` で保存します。クリア回数は増えるので `updateHighScore` を使います。キーは `js-mini-games-maze-best` と `js-mini-games-maze-clears` です。

## 遊び方

1. `index.html` をブラウザで開く。左上の金色が自分、右下の緑がゴールです。
2. 矢印キーか WASD で、通路を1マスずつ進みます。壁の方向を押しても動きません。
3. 進めた回数は「手数」に出ます。
4. ゴールに着くとクリアです。これまでより少ない手数のときだけ「最短」が更新され、「最短記録です！」と出ます。
5. 「もう一度」で新しい迷路になり、手数は 0 に戻ります。最短とクリア回数は残ります。ページを再読み込みしても残っています。

## ファイルの役割

| ファイル | 役割 |
| --- | --- |
| `index.html` | 見出し、記録の置き場、Canvas、メッセージ。「もう一度」の置き場。`common.css` / `common.js` を相対パスで読み込む。 |
| `style.css` | 記録の3列、盤面を中央に置く大きさ。 |
| `script.js` | 壁の配列、穴掘り法、移動、ゴール判定、最短手数とクリア回数。 |
| `../../common/common.js` | `getRandomInt`、`createScoreDisplay`、`updateScore`、`showMessage`、`clearMessage`、`createRestartButton`、`getHighScore`、`setHighScore`、`updateHighScore`。 |
| `../../common/common.css` | 画面中央のレイアウト、暗い背景、スコア、メッセージ、ボタン。 |

## 読んでみる順番

1. `createWalls` で、全部が `"wall"` の2次元配列になることを確認する。
2. `carve` で、2マス先へ進むときにあいだの壁を `"path"` へ変えている箇所を見る。
3. `tryMove` で、壁なら位置を変えず、通路なら手数を足す流れを追う。
4. `finishGame` で、最短手数だけ大小が逆になっている理由を確認する。

小さく改造するなら、`SIZE` を `11` に変えてみてください。迷路が小さくなります。偶数にはしないでください。

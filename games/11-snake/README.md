# 11 スネーク

矢印キーか WASD で蛇を動かし、緑の餌を食べます。食べると体が1マス伸び、スコアが1増えます。壁か自分の体に当たるとゲームオーバーです。「もう一度」でやり直せます。最高記録はブラウザに保存されるので、ページを再読み込みしても残ります。

## このゲームで学ぶ概念

- **Canvas** … `getContext("2d")` で描画口を取り、`fillRect` で四角を塗ります。毎ターン一度背景を消してから、蛇と餌を描き直します。
- **アニメーション** … `requestAnimationFrame` は、次の画面更新のタイミングで関数を呼びます。間隔は一定ではないので、前回から `MOVE_EVERY_MS` 以上たっているときだけ蛇を1マス進めます。
- **なぜ `createTimer` を使わないか** … `createTimer` は 1 秒ごとにしか進みません。蛇の移動はそれより短い間隔で、描画のタイミングに合わせたいので `requestAnimationFrame` を使います。
- **キーボード** … `keydown` で押されたキーを受け取り、方向を `{ x, y }` に変えます。矢印キーでは `preventDefault` して、ページがスクロールしないようにします。
- **配列** … 蛇の体は `{ x, y }` の配列です。先頭が頭です。進むときは頭を `unshift` し、食べていないときは尻尾を `pop` します。
- **衝突** … 次の頭が盤面の外なら壁です。自分の体のマスと重なれば自分に当たったことになります。食べないとき、今の尻尾のマスは次に空くので衝突にしません。
- **関数の再利用** … スコア、最高記録、結果メッセージ、もう一度ボタン、餌の位置の乱数は `common.js` に任せます。最高記録の読み書きは `getHighScore` と `updateHighScore` です。
- **localStorage** … ゲームオーバーのとき、今回の得点が保存済みの記録より大きいときだけ書き込みます。キーは `js-mini-games-snake-highscore` です。

## 遊び方

1. `index.html` をブラウザで開く。蛇は止まった状態です。
2. 矢印キーか WASD を押すと、その方向へ動き出します。
3. 緑のマスが餌です。頭が重なると体が伸び、スコアが 1 増えます。
4. 進行方向の真後ろには、すぐに引き返せません。
5. 壁か自分の体に当たるとゲームオーバーになります。得点がこれまでの最高より大きいときだけ、最高記録が更新され、「最高記録です！」と出ます。
6. 「もう一度」で蛇とスコアが最初に戻ります。最高記録は残ります。ページを再読み込みしても、最高記録は残っています。

## ファイルの役割

| ファイル | 役割 |
| --- | --- |
| `index.html` | 見出し、スコアの置き場、Canvas、メッセージ。「もう一度」の置き場。`common.css` / `common.js` を相対パスで読み込む。 |
| `style.css` | スコアの2列、盤面を中央に置く大きさ。 |
| `script.js` | マスの数と速度、蛇の配列、描画、キーボード、衝突、最高記録。 |
| `../../common/common.js` | `getRandomInt`、`createScoreDisplay`、`updateScore`、`showMessage`、`clearMessage`、`createRestartButton`、`getHighScore`、`updateHighScore`。 |
| `../../common/common.css` | 画面中央のレイアウト、暗い背景、スコア、メッセージ、ボタン。 |

## 読んでみる順番

1. `draw` と `fillCell` で、`fillRect` がどの四角を塗っているかを見る。
2. `loop` で、`requestAnimationFrame` が自分をもう一度呼ぶ流れを追う。
3. `step` で、頭を足して尻尾を消すときと、消さないとき（餌）の違いを確認する。
4. `onKeyDown` と `setDirection` で、キーが方向になり、真後ろを無視する箇所を見る。
5. `finishGame` で、`updateHighScore` が記録を超えたときだけ保存している箇所を確認する。

小さく改造するなら、`MOVE_EVERY_MS` を `100` に変えてみてください。蛇の進みが速くなります。

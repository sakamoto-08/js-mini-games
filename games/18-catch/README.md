# 18 キャッチゲーム

下のバーを左右に動かし、上から落ちてくる金の丸をキャッチします。1つ取るとスコアが1増えます。赤い四角を取るとライフが1減ります。取り逃したものは、画面の下で消えるだけです。ライフが0になるか、30秒たつとゲームオーバーです。「もう一度」でやり直せます。最高記録は、ページを再読み込みするまで残ります。

## このゲームで学ぶ概念

- **落ちてくるものの配列** … アイテムは `{ x, y, kind, caught }` の配列 `items` です。`kind` は `"good"` か `"bad"` です。
- **生成と削除** … 一定時間ごとに `push` で配列へ足します。取ったものと、下まで落ちたものは `filter` で配列から除きます。
- **矩形の当たり判定** … バーとアイテムを、どちらも四角の重なりで調べます。金の丸は見た目だけ円です。
- **アニメーション** … `requestAnimationFrame` で毎フレーム動かし、前回からの秒数を速度に掛けます。残り時間は `createTimer` が1秒ごとに減らします。
- **キーボードとマウス** … 左右キーは押し続けているあいだ動きます。マウスやタッチは、盤面の上でバーの位置を直接決めます。
- **関数の再利用** … スコア、最高記録、ライフ、残り時間、結果メッセージ、もう一度ボタンは `common.js` に任せます。

## 遊び方

1. `index.html` をブラウザで開く。アイテムはまだ落ちてきません。
2. 左右の矢印キーか A / D、または盤面の上でマウスを動かします。最初の操作で落下と30秒のタイマーが始まります。
3. 金の丸にバーを当てるとスコアが1増えます。
4. 赤い四角に当てるとライフが1減ります。ライフの最初の値は3です。
5. 取り逃しても減点にはなりません。画面の下まで行くと消えます。
6. ライフが0になるか、残り時間が0になるとゲームオーバーです。得点がこれまでの最高より大きいときだけ、最高記録が更新されます。
7. 「もう一度」でスコア、ライフ、残り時間が最初に戻ります。最高記録は残ります。

## ファイルの役割

| ファイル | 役割 |
| --- | --- |
| `index.html` | 見出し、スコアの置き場、Canvas、メッセージ。「もう一度」の置き場。`common.css` / `common.js` を相対パスで読み込む。 |
| `style.css` | スコアの2列、盤面を中央に置く大きさ。 |
| `script.js` | 落下物の配列、当たり判定、キーボードとマウス、制限時間、最高記録。 |
| `../../common/common.js` | `createScoreDisplay`、`updateScore`、`showMessage`、`clearMessage`、`createRestartButton`、`createTimer`、`getRandomInt`。 |
| `../../common/common.css` | 暗い背景、スコア、メッセージ、ボタン。 |

## 読んでみる順番

1. `spawnItem` で、アイテムが配列にどう足されるかを見る。
2. `moveItems` と `resolveCatches` の `filter` で、落ちたものと取ったものがどう消えるかを追う。
3. `rectsOverlap` で、バーとアイテムの重なりを判定している箇所を確認する。
4. `loop` と `movePlayerToPointer` で、毎フレームの動きと、キーとマウスの違いを見る。

小さく改造するなら、`FALL_SPEED` を `220` に変えてみてください。アイテムの落ちる速さが上がります。

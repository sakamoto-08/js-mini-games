# 02 じゃんけん

プレイヤーがグー・チョキ・パーのどれかを選ぶと、コンピュータも手を出します。勝ち・負け・あいこを数えて、何度でも続けられます。

## このゲームで学ぶ概念

- **配列** … 出せる手を `HANDS` にまとめる。`HANDS[0]` はグー、`length` は個数。ボタンもこの配列から作る。
- **オブジェクト** … `WIN_AGAINST` に「どの手がどの手に勝つか」を書く。`scores` には勝ち・負け・あいこの回数をまとめる。
- **関数の分割** … コンピュータの手を選ぶ処理、勝敗判定、メッセージ文、スコア加算を別々の関数にする。
- **イベント** … 各ボタンの `click` で `playRound` を呼ぶ。
- **乱数** … `getRandomInt(0, HANDS.length - 1)` で配列の位置を決める。
- **関数の再利用** … スコア表示、メッセージ、リセットボタンは `common.js` に任せる。

## 遊び方

1. `index.html` をブラウザで開く。
2. 「グー」「チョキ」「パー」のどれかを押す。
3. コンピュータの手と、勝ち / 負け / あいこ が表示される。押すたびに対応する回数が 1 増える。
4. そのまま別の手を押せば、次の勝負が始まる。
5. 「リセット」で、3つの回数と結果表示が最初の状態に戻る。

## ファイルの役割

| ファイル | 役割 |
| --- | --- |
| `index.html` | 見出し、スコアの置き場、手ボタンの置き場、対戦結果、メッセージ。`common.css` / `common.js` を相対パスで読み込む。 |
| `style.css` | 3つのスコアと手ボタンの横並び、対戦欄。カード自体の見た目は共通側。 |
| `script.js` | 手の配列、勝敗ルール、判定、スコア更新、リセット。 |
| `../../common/common.js` | `getRandomInt`、`createScoreDisplay`、`updateScore`、`showMessage`、`clearMessage`、`createRestartButton`。 |
| `../../common/common.css` | 画面中央のレイアウト、暗い背景、スコア、メッセージ、ボタン。 |

## 読んでみる順番

1. `script.js` の先頭にある `HANDS` と `WIN_AGAINST` を見る。
2. `judge` が、そのオブジェクトをどう使って勝ち負けを分けているかを追う。
3. ボタンを作っている `for` と、クリックされたときの `playRound` をつなげて読む。

小さく改造するなら、`buildMessage` の文言を変えてみてください。ルールを変える場合は `WIN_AGAINST` だけを直せば、判定の `if` は触らなくて済みます。

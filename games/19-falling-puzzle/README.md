# 19 落ちものパズル

上から落ちてくるブロックを左右に動かし、回しながら積みます。横一列が埋まるとその列が消え、上のブロックが下へずれます。次のブロックを置く場所が無くなるとゲームオーバーです。「もう一度」でやり直せます。最高記録はブラウザに保存されるので、ページを再読み込みしても残ります。

## このゲームで学ぶ概念

- **2次元配列** … 盤面は `board[行][列]` です。空きは `null`、着地したマスはそのブロックの色です。
- **落下と着地** … 下のマスが空なら `y` を 1 増やします。空でなければ、いまのマスを盤面へ書き込んで次のブロックを出します。
- **行の消去** … 1行が端から端まで埋まっていたら、その行を配列から取り除きます。上にあった行は、そのまま1段下の番号になります。
- **回転** … 1つのブロックは、向きごとのマス一覧を持っています。次の向きにして、盤面の外や既存のマスに重なるなら回転しません。壁のそばでは、左右へ少しずらしてから試します。
- **状態** … `gameState` が `"ready"` のあいだは落ちません。左右・下・回転のキーで `"playing"` になり、置けなくなると `"finished"` です。
- **アニメーション** … `requestAnimationFrame` が次の画面更新で `loop` を呼びます。前回から `FALL_EVERY_MS` 以上たっているときだけ、1マス落とします。
- **なぜ `createTimer` を使わないか** … `createTimer` は 1 秒ごとにしか進みません。落下はそれより短い間隔で、描画のタイミングに合わせたいので `requestAnimationFrame` を使います。
- **関数の再利用** … スコア、最高記録、結果メッセージ、もう一度ボタン、次の形の乱数は `common.js` に任せます。最高記録の読み書きは `getHighScore` と `updateHighScore` です。
- **localStorage** … ゲームオーバーのとき、今回の得点が保存済みの記録より大きいときだけ書き込みます。キーは `js-mini-games-falling-puzzle-highscore` です。

## 遊び方

1. `index.html` をブラウザで開く。ブロックは止まった状態です。
2. 左右の矢印キーか A / D で横へ動かします。押し続けているあいだ動きます。最初の操作で落下も始まります。
3. 下キーか S で、いつもより速く落ちます。
4. スペースか、上キーか W で回します。四角のブロックは回しても形が変わりません。
5. 横一列が埋まると消え、得点が増えます。1列は 100 点、2列は 300 点、3列は 500 点、4列は 800 点です。
6. 次のブロックが天井に重なるとゲームオーバーです。得点がこれまでの最高より大きいときだけ、最高記録が更新され、「最高記録です！」と出ます。
7. 「もう一度」で盤面とスコアが最初に戻ります。最高記録は残ります。ページを再読み込みしても、最高記録は残っています。

## ファイルの役割

| ファイル | 役割 |
| --- | --- |
| `index.html` | 見出し、スコアの置き場、Canvas、メッセージ。「もう一度」の置き場。`common.css` / `common.js` を相対パスで読み込む。 |
| `style.css` | スコアの3列、盤面を中央に置く大きさ。 |
| `script.js` | 盤面の配列、4種類の形、落下、回転、列の消去、操作、最高記録。 |
| `../../common/common.js` | `getRandomInt`、`createScoreDisplay`、`updateScore`、`showMessage`、`clearMessage`、`createRestartButton`、`getHighScore`、`updateHighScore`。 |
| `../../common/common.css` | 画面中央のレイアウト、暗い背景、スコア、メッセージ、ボタン。 |

## 読んでみる順番

1. `createBoard` と `cellsOf` で、2次元配列と落ちているブロックの関係を見る。
2. `fits` と `stepDown` で、下へ進めるときと、着地して固定するときの違いを追う。
3. `clearLines` で、埋まった行を消したあと、なぜ同じ行番号をもう一度調べるのかを確認する。
4. `rotatePiece` で、次の向きが重なるときに左右へずらしている箇所を見る。
5. `loop` で、`requestAnimationFrame` と落下間隔の使い方を確認する。
6. `finishGame` で、`updateHighScore` が記録を超えたときだけ保存している箇所を確認する。

小さく改造するなら、`FALL_EVERY_MS` を `900` に変えてみてください。ブロックの落ち方がゆっくりになります。

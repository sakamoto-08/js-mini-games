# 07 タイピング

「スタート」から 60 秒のあいだに、表示された英単語をそのまま入力します。一致すると次の単語になり、正解数が 1 増えます。時間切れになると正解数と最高記録が出ます。最高記録は、ページを再読み込みするまで残ります。

## このゲームで学ぶ概念

- **キーボードイベント** … `input` は文字が入ったあとに、入力欄の中身を比べる。`keydown` はキーが押された瞬間で、ここでは Enter の答え合わせに使う。
- **文字列の比較** … `===` で全部一致したかを見る。`indexOf` が 0 なら、入力が単語の先頭と一致している。
- **配列** … 出題は `WORDS` にまとめておく。語を足すときは、この配列に文字列を追加する。
- **ランダム** … `getRandomInt` で配列の位置を選び、次の単語を決める。
- **タイマー** … 残り時間は `createTimer`。時間切れでは `stop` して、それ以上入力できないようにする。
- **状態** … `gameState` が `"playing"` のときだけ正解にする。
- **関数の再利用** … スコア、メッセージ、タイマー、乱数、もう一度ボタンは `common.js` に任せる。

## 遊び方

1. `index.html` をブラウザで開く。
2. 「スタート」を押す。残り時間が 60 から減り、英単語が 1 つ出る。
3. 表示どおりに入力する。合っているあいだは枠が緑、違う文字があると赤になる。
4. 最後まで一致すると、すぐに次の単語へ進み、正解数が 1 増える。
5. 0 秒になると、正解数と最高記録かどうかが表示される。
6. 「もう一度」で正解数と残り時間が最初に戻る。最高記録は残る。

単語は小文字です。大文字で入れると、別の文字列として扱います。Enter を押したとき、まだ一致していなければメッセージが出ます。

## ファイルの役割

| ファイル | 役割 |
| --- | --- |
| `index.html` | 見出し、スコアの置き場、単語、入力欄、スタートボタン、メッセージ。`common.css` / `common.js` を相対パスで読み込む。 |
| `style.css` | 単語の大きさ、入力欄、合っているときと違うときの枠の色。 |
| `script.js` | 単語リスト、文字列の比較、正解、制限時間、最高記録。 |
| `../../common/common.js` | `getRandomInt`、`createScoreDisplay`、`updateScore`、`showMessage`、`clearMessage`、`createTimer`、`createRestartButton`。 |
| `../../common/common.css` | 画面中央のレイアウト、暗い背景、スコア、メッセージ、ボタン。 |

## 読んでみる順番

1. `WORDS` と `pickWord` で、次の単語が配列からどう選ばれるかを見る。
2. `checkTypedText` と `updateFeedback` で、`===` と `indexOf` の違いを追う。
3. `handleTick` と `finishGame` で、時間切れのときに何が止まるかを確認する。

小さく改造するなら、`WORDS` に自分の知っている単語を 1 つ足してみてください。画面に出る語が増えます。

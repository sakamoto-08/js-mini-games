# 01 数当てゲーム

1〜100 の整数を、コンピュータが1つ決めます。プレイヤーは数字を入力し、「もっと大きい」「もっと小さい」のヒントだけで正解に近づきます。

## このゲームで学ぶ概念

- **変数と定数** … 正解 (`answer`) や試行回数 (`attempts`) はプレイ中に変わるので `let`。範囲 (`MIN_NUMBER`) は変わらないので `const`。
- **乱数** … `getRandomInt` で範囲つきの整数を作る。中身は `Math.random()`。
- **条件分岐** … `if` / `else if` / `else` で、正解・大きい・小さい・入力エラーを分ける。
- **比較** … `===`（同じ）、`<`（小さい）、`>` に相当する「大きい」側のヒント。
- **イベント** … フォームの `submit` を受け取り、`preventDefault()` でページ再読み込みを止める。
- **DOM** … 入力欄の有効・無効、メッセージの表示、試行回数の更新。
- **関数の再利用** … 乱数・スコア・メッセージ・リスタートは `common.js` に任せ、このファイルはゲームのルールに集中する。

## 遊び方

1. `index.html` をブラウザで開く。
2. 1〜100 の整数を入力し、「答える」を押す（Enter でも可）。
3. ヒントを見て、次の数字を入れる。入れるたびに試行回数が 1 増える。
4. 正解すると結果メッセージが出る。「もう一度遊ぶ」で別の数字に挑める。

1 未満、100 超過、整数でない値はエラーメッセージになり、試行回数は増えません。

## ファイルの役割

| ファイル | 役割 |
| --- | --- |
| `index.html` | 見出し、入力フォーム、メッセージを置く場所。`common.css` / `common.js` を相対パスで読み込む。 |
| `style.css` | 入力欄とフォームの並び。ボタンやスコアの基本スタイルは共通側。 |
| `script.js` | 正解の決定、判定、ヒント、終了とやり直し。 |
| `../../common/common.js` | `getRandomInt`、`createScoreDisplay`、`updateScore`、`showMessage`、`clearMessage`、`createRestartButton`。 |
| `../../common/common.css` | 画面中央のレイアウト、暗い背景、スコア、メッセージ、ボタン。 |

## 読んでみる順番

1. `index.html` で、どの要素に `id` が付いているかを見る。
2. `script.js` の `startGame` と `handleGuess` を追う。
3. 呼ばれている共通関数の中身を `common.js` で確認する。

小さく改造するなら、最初は `MIN_NUMBER` と `MAX_NUMBER` を変えてみてください。表示テキストと `index.html` の `min` / `max` も一緒に直す必要があります。

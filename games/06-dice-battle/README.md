# 06 サイコロ勝負

「サイコロを振る」を押すと、あなたとコンピュータが 1〜6 の目を 1 つずつ出します。大きい方が勝ち、同じならあいこです。何度でも続けられ、勝ち・負け・あいこの回数は「リセット」で 0 に戻ります。

## このゲームで学ぶ概念

- **乱数** … `getRandomInt(1, 6)` で出目を作る。1 も 6 も出る。
- **条件分岐** … `judge` が `===` と `>` で、あいこ・勝ち・負けを分ける。
- **DOM の更新** … 出目が決まったら、サイコロの点（クラス `on`）と下の数字を書き換える。
- **状態** … 勝ち・負け・あいこの回数は `scores` に保持する。表示は `updateScore` でその中身に合わせる。
- **関数の分割** … 出目を決める、画面に出す、勝敗を決める、文章を作る、を別々の関数にする。
- **関数の再利用** … 乱数、スコア、メッセージ、リセットボタンは `common.js` に任せる。

## 遊び方

1. `index.html` をブラウザで開く。
2. 「サイコロを振る」を押す。
3. 2つの出目と、勝ち / 負け / あいこ が表示される。押すたびに対応する回数が 1 増える。
4. そのままもう一度押せば、次の勝負が始まる。
5. 「リセット」で、3つの回数と出目の表示が最初の状態に戻る。

## ファイルの役割

| ファイル | 役割 |
| --- | --- |
| `index.html` | 見出し、スコアの置き場、2つのサイコロ、振るボタン、メッセージ。`common.css` / `common.js` を相対パスで読み込む。 |
| `style.css` | サイコロの形と点、2つを横に並べる配置。 |
| `script.js` | 出目、点の付け方、勝敗、スコア、リセット。 |
| `../../common/common.js` | `getRandomInt`、`createScoreDisplay`、`updateScore`、`showMessage`、`clearMessage`、`createRestartButton`。 |
| `../../common/common.css` | 画面中央のレイアウト、暗い背景、スコア、メッセージ、ボタン。 |

## 読んでみる順番

1. `rollDie` と `judge` で、出目がどう決まり、どう勝敗になるかを見る。
2. `PIP_LAYOUTS` と `showFace` で、数字が画面の点に変わっていくところを追う。
3. `playRound` が、それらをどの順で呼んでいるかを確認する。

小さく改造するなら、`buildMessage` の文言を変えてみてください。出目の範囲を変える場合は `MIN_FACE` と `MAX_FACE` だけでなく、`PIP_LAYOUTS` も一緒に直す必要があります。

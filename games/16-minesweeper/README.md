# 16 マインスイーパー

閉じたマスを開いて、地雷を避けます。数字は、そのマスの周囲8マスにある地雷の数です。周囲に地雷がないマスを開くと、となりも連鎖して開きます。地雷を開くとゲームオーバー、地雷以外を全部開くとクリアです。終わったときに、かかった秒数を表示します。「もう一度」で最初からやり直せます。

## このゲームで学ぶ概念

- **2次元配列** … 盤面は `board[行][列]` です。1マスは `{ mine, adjacent, open, flagged }` を持つオブジェクトです。
- **周囲8マス** … 行と列を −1、0、+1 ずらした組み合わせを順に見て、盤面の外は数えないようにします。
- **再帰** … 空白マスを開いたとき、`openCell` が周囲のマスに対して自分自身を呼びます。開いたマスは先に印を付けるので、同じマスを何度も開きません。
- **状態** … `gameState` は `"ready"`（地雷を置く前）、`"playing"`（タイマーが進む）、`"finished"`（クリアかゲームオーバー）のどれかです。
- **タイマー** … 最初のクリックで `createTimer` を開始し、終わったときに止めます。表示の更新は `updateScore` です。
- **関数の再利用** … 時間、残りマス、結果メッセージ、もう一度ボタンは `common.js` に任せます。

## 遊び方

1. `index.html` をブラウザで開く。マスはすべて閉じています。
2. マスを左クリックして開きます。最初の1手とその周りには地雷がありません。周りに地雷がなければ、となりのマスも開きます。
3. 数字は、周囲8マスの地雷の数です。
4. 右クリック、または長押しで旗を立てます。もう一度行うと旗が外れます。旗のあるマスは開けません。
5. 地雷を開くとゲームオーバーです。全部の地雷が見え、かかった秒数が出ます。
6. 地雷以外をすべて開くとクリアです。同じく秒数が出ます。
7. 「もう一度」で盤面を作り直し、時間を 0 に戻します。

## ファイルの役割

| ファイル | 役割 |
| --- | --- |
| `index.html` | 見出し、時間の置き場、盤面、メッセージ。「もう一度」の置き場。`common.css` / `common.js` を相対パスで読み込む。 |
| `style.css` | スコアの 2 列、閉じたマス・開いたマス・旗・地雷・数字の色。 |
| `script.js` | 2次元配列、周囲8マス、再帰で開く処理、タイマー、クリア判定。 |
| `../../common/common.js` | `createScoreDisplay`、`updateScore`、`showMessage`、`clearMessage`、`createRestartButton`、`createTimer`、`getRandomInt`。 |
| `../../common/common.css` | 暗い背景、スコア、メッセージ、ボタン。 |

## 読んでみる順番

1. `createEmptyBoard` で、行と列の配列がどう分かれるかを見る。
2. `forEachNeighbor` と `countNeighborMines` で、周囲8マスの数え方を追う。
3. `openCell` で、空白のときに自分を呼び直している箇所を確認する。
4. `openAt` と `finishGame` で、最初のクリック、タイマーの開始と停止、クリアとゲームオーバーの分かれ目を見る。

小さく改造するなら、`MINE_COUNT` を `15` に変えてみてください。地雷が増えて、空きマスが減ります。

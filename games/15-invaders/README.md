# 15 インベーダー

下の自機を左右に動かし、スペースで弾を撃って上の敵を倒します。1体倒すとスコアが 1 増えます。全部倒すとクリアです。敵が自機の高さまで降りるか、自機に重なるとゲームオーバーです。「もう一度」でやり直せます。最高記録は、ページを再読み込みするまで残ります。

## このゲームで学ぶ概念

- **配列で複数の敵** … 敵は `{ x, y, row, alive }` の配列です。倒した敵は消さずに `alive` を false にして、描画と当たり判定から外します。
- **弾の配列** … 撃つたびに `bullets` へオブジェクトを足します。上に出たか、敵に当たった弾は `filter` で配列から除きます。
- **グループの移動** … 残っている敵を同じ量だけ横へ動かします。どれか1体でも端に着くなら、そのフレームは全員を下げて、向きを反転します。
- **当たり判定** … 弾と敵、敵と自機を、どちらも四角の重なりで調べます。1発の弾は、最初に当たった1体だけを倒します。
- **状態** … `gameState` が `"ready"` のあいだ敵は止まります。左右キーかスペースで `"playing"` になり、クリアかゲームオーバーで `"finished"` です。
- **関数の再利用** … スコア、最高記録、結果メッセージ、もう一度ボタンは `common.js` に任せます。

## 遊び方

1. `index.html` をブラウザで開く。敵は止まった状態です。
2. 左右の矢印キーか A / D で自機を動かします。押し続けているあいだ動きます。最初の操作で敵も動き出します。
3. スペースで弾を撃ちます。短い間隔を空けて、複数の弾を同時に飛ばせます。
4. 弾が敵に当たるとその敵が消え、スコアが 1 増えます。
5. 敵は端まで行くと一段下がり、反対向きに進みます。
6. 全部倒すとクリアです。自機の高さまで降りるとゲームオーバーです。
7. 「もう一度」で敵とスコアが最初に戻ります。最高記録は残ります。

## ファイルの役割

| ファイル | 役割 |
| --- | --- |
| `index.html` | 見出し、スコアの置き場、Canvas、メッセージ。「もう一度」の置き場。`common.css` / `common.js` を相対パスで読み込む。 |
| `style.css` | スコアの 2 列、盤面を中央に置く大きさ。 |
| `script.js` | 敵の行と列、弾の配列、グループ移動、当たり判定、最高記録。 |
| `../../common/common.js` | `createScoreDisplay`、`updateScore`、`showMessage`、`clearMessage`、`createRestartButton`。 |
| `../../common/common.css` | 暗い背景、スコア、メッセージ、ボタン。 |

## 読んでみる順番

1. `createEnemies` で、行と列から配列の1体がどう決まるかを見る。
2. `moveEnemies` で、端に着いたときに下へ下がって向きが変わる箇所を追う。
3. `fire` と `moveBullets` で、弾が配列に入り、あとから消える流れを確認する。
4. `resolveHits` と `enemiesReachedPlayer` で、弾と敵、敵と自機の判定の違いを見る。

小さく改造するなら、`ENEMY_COLS` を `8` に変えてみてください。横の敵が1列増えます。

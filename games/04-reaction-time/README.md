# 04 反応速度

「スタート」を押すと、1〜5秒のあいだ待機になります。画面が明るく変わったら、すぐにクリックしてください。変わってから押すまでのミリ秒が記録です。変わる前に押すとフライングになり、記録は残りません。

## このゲームで学ぶ概念

- **setTimeout** … ランダムなミリ秒のあとで、合図を出す関数を予約する。フライングのときは `clearTimeout` で、その予約を取り消す。
- **時間の計測** … 合図の瞬間に `performance.now()` を控え、クリック時の値から引く。`createTimer` は 1 秒単位なので、このゲームでは使わない。
- **状態** … `gameState` は `"ready"` / `"waiting"` / `"go"` / `"finished"` のどれか。押したときの処理は、この状態で決まる。
- **フライング判定** … `"waiting"` のクリックは記録にせず、合図も出さない。`"go"` のクリックだけを計測する。
- **比較** … 最高記録は大きい方が勝ちではなく、より短い時間。まだ記録が無いときは `null` と比べない。
- **関数の再利用** … 待ち時間の乱数、スコア、メッセージ、もう一度ボタンは `common.js` に任せる。

## 遊び方

1. `index.html` をブラウザで開く。
2. 「スタート」を押す。ボタンが「待機中…」になる。
3. 画面が緑に変わり「今すぐクリック！」と出たら、すぐ押す。
4. ミリ秒と、これまでの最高記録が表示される。短いほど良い記録です。
5. 変わる前に押すと「フライング」になり、今回の記録は残りません。
6. 「もう一度」で最初からやり直せる。最高記録は、ページを再読み込みするまで残る。

## ファイルの役割

| ファイル | 役割 |
| --- | --- |
| `index.html` | 見出し、スコアの置き場、合図用の大きなボタン、スタートボタン、メッセージ。`common.css` / `common.js` を相対パスで読み込む。 |
| `style.css` | 待機中と「今すぐクリック！」で、カードとボタンの色を切り替える。 |
| `script.js` | ランダムな待ち時間、フライング判定、ミリ秒の計測、最高記録。 |
| `../../common/common.js` | `getRandomInt`、`createScoreDisplay`、`updateScore`、`showMessage`、`clearMessage`、`createRestartButton`。 |
| `../../common/common.css` | 画面中央のレイアウト、暗い背景、スコア、メッセージ、ボタン。 |

## 読んでみる順番

1. `script.js` の `gameState` と `handleTargetClick` で、待機中と合図のあとで処理がどう分かれるかを見る。
2. `startRound` の `setTimeout` と、フライング時の `clearTimeout` を対応させる。
3. `showGoSignal` と `finishRound` で、`performance.now()` の差が記録になっていることを追う。

小さく改造するなら、`MIN_DELAY` と `MAX_DELAY` を変えてみてください。待ち時間の範囲だけが変わります。

# 08 神経衰弱

16枚のカードから、同じ絵柄を2枚ずつ揃えます。2枚めくるたびに手数が1増えます。全部揃えるとクリアです。「もう一度」でカードをシャッフルし直します。最少手数は、ページを再読み込みするまで残ります。

## このゲームで学ぶ概念

- **配列** … カードの絵柄は `SYMBOLS` にまとめ、2枚ずつにした配列をシャッフルして盤面にします。
- **シャッフル** … `shuffle` はうしろから順に、ランダムな位置と中身を交換します。乱数は `getRandomInt` です。
- **状態** … 各カードは「表か裏か」「揃ったか」を持ちます。ゲーム全体は `playing` か `finished` です。裏に戻る待ちのあいだは `locked` です。
- **DOM** … カードのボタンは JavaScript で作ります。表裏は `is-up`、揃ったカードは `is-matched` というクラスの付け外しで切り替えます。
- **タイマー** … 絵柄が違うときは `setTimeout` で少し待ってから裏に戻します。1秒ごとに増える `createTimer` とは役割が違います。
- **イベント** … `locked` が true のときや、すでに表のカードをクリックしたときは、何もしません。
- **関数の再利用** … 手数、ペア数、結果メッセージ、もう一度ボタンは `common.js` に任せます。

## 遊び方

1. `index.html` をブラウザで開く。カードはすべて裏向きです。
2. カードを1枚クリックすると表になります。
3. もう1枚めくります。同じ絵柄ならそのまま残り、違う絵柄なら少し待って裏に戻ります。
4. 2枚めくるたびに手数が1増えます。揃ったペアの数も増えます。
5. 8ペア全部揃えると、手数と最少手数かどうかが表示されます。
6. 「もう一度」で並びがシャッフルされ、手数とペア数が0に戻ります。最少手数は残ります。

違う絵柄を待っているあいだは、次のカードをめくれません。同じカードを2回めくっても、手数は増えません。

## ファイルの役割

| ファイル | 役割 |
| --- | --- |
| `index.html` | 見出し、スコアの置き場、盤面、メッセージ。「もう一度」の置き場。`common.css` / `common.js` を相対パスで読み込む。 |
| `style.css` | 4列のグリッド、裏向きと表向き、揃ったカードの色。 |
| `script.js` | カードの配列、シャッフル、表裏、不一致の待ち時間、クリア判定。 |
| `../../common/common.js` | `getRandomInt`、`createScoreDisplay`、`updateScore`、`showMessage`、`clearMessage`、`createRestartButton`。 |
| `../../common/common.css` | 画面中央のレイアウト、暗い背景、スコア、メッセージ、ボタン。 |

## 読んでみる順番

1. `createDeck` と `shuffle` で、ペアがどう作られ、どう並び替わるかを見る。
2. `flipCard` で、1枚目と2枚目の違い、`locked` でクリックを止める理由を追う。
3. `scheduleFlipBack` で、`setTimeout` のあと何が裏に戻るかを確認する。

小さく改造するなら、`SYMBOLS` に絵文字を1つ足してみてください。その絵柄のカードが2枚増えます。

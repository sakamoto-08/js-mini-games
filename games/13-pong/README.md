# 13 ポン

左のバーを上下に動かし、ボールを右のコンピュータへ打ち返します。ボールが左右の端に入ると、入れられた側の相手に 1 点入ります。先に 5 点取った方が勝ちです。「もう一度」でやり直せます。

## このゲームで学ぶ概念

- **Canvas** … 背景、中央の点線、左右のバーは `fillRect`、ボールは `arc` で描きます。毎フレーム、一度消してから描き直します。
- **アニメーション** … `requestAnimationFrame` が `loop` を繰り返し呼びます。前回からの秒数を速度に掛けるので、フレームが揺れてもボールの速さはほぼ一定です。
- **押しっぱなし** … `keydown` で「押されている」を true にし、`keyup` で false に戻します。毎フレーム、押されているあいだだけバーを動かします。
- **簡単な AI** … 右のバーは、ボールが右へ来ているときだけ、その高さへ `AI_SPEED` まで近づきます。プレイヤーより遅いので、角度をつければ抜けます。
- **衝突** … 上下の壁は、はみ出した座標で跳ね返します。バーは、円と長方形が重なったか、1 フレームでバーの前を横切ったかで判定します。
- **勝敗** … 左右の得点を別々に数え、どちらかが `WIN_SCORE` に届いたら終了です。
- **関数の再利用** … 左右の得点、勝敗メッセージ、もう一度ボタン、サーブの角度の乱数は `common.js` に任せます。

## 遊び方

1. `index.html` をブラウザで開く。ボールは中央で止まっています。
2. スペースか、盤面のクリックで試合が始まります。
3. 上キー / W でバーを上げ、下キー / S で下げます。押し続けているあいだ動きます。
4. 左の端に入ると CPU の点、右の端に入るとあなたの点です。次のボールは、落とした側へ向かいます。
5. 先に 5 点取ると勝敗が出ます。
6. 「もう一度」で 0 対 0 に戻ります。

右のバーは金色ではなく青です。ボールが右へ進んでいるときだけ、ボールの高さを追います。

## ファイルの役割

| ファイル | 役割 |
| --- | --- |
| `index.html` | 見出し、左右の得点の置き場、Canvas、メッセージ。「もう一度」の置き場。`common.css` / `common.js` を相対パスで読み込む。 |
| `style.css` | 横長の盤面、得点の 2 列、このゲームだけ少し広いカード。 |
| `script.js` | バーとボールの速度、描画、衝突、AI、5 点先取の勝敗。 |
| `../../common/common.js` | `getRandomInt`、`createScoreDisplay`、`updateScore`、`showMessage`、`clearMessage`、`createRestartButton`。 |
| `../../common/common.css` | 暗い背景、スコア、メッセージ、ボタン。 |

## 読んでみる順番

1. `draw` で、バーとボールと中央線がどの順で塗られるかを見る。
2. `onKeyDown` と `movePlayer` で、押しっぱなしがどうバーの移動になるかを追う。
3. `moveAi` で、ボールの `vx` によって追う目標が変わる箇所を確認する。
4. `moveBall` と `scorePoint` で、端に入ったときの得点と、5 点で終わる判定を見る。

小さく改造するなら、`AI_SPEED` を `80` に変えてみてください。右のバーの反応が遅くなります。

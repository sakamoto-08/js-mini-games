# 10 クイズ

問題を1問ずつ出し、4つの中から答えを選びます。選ぶとすぐに正解か不正解かがわかり、解説が出ます。「次の問題へ」で進み、最後に正解数と正答率が出ます。「もう一度」で1問目に戻ります。

## このゲームで学ぶ概念

- **配列とオブジェクト** … 問題は `QUESTIONS` という配列です。1問は `question`、`choices`、`correctIndex`、`explanation` を持つオブジェクトです。
- **インデックス** … `currentIndex` がいまの問題番号です。配列と同じく、最初は 0 です。`correctIndex` も、選択肢の 0 から数えた番号です。
- **状態** … `quizState` が `"answering"` のときだけ答えを受け付けます。解説を出しているあいだは `"revealed"`、全問終わったら `"finished"` です。
- **DOM** … 選択肢のボタンは、問題が変わるたびに JavaScript で作り直します。正解は `is-correct`、選んだ間違いは `is-wrong` というクラスで色を変えます。
- **関数の再利用** … 正解数、問題番号、解説メッセージ、もう一度ボタンは `common.js` に任せます。

## 遊び方

1. `index.html` をブラウザで開く。1問目と4つの選択肢が出ます。
2. 選択肢を1つ押す。正解なら緑、間違えた選択は赤になり、解説が出ます。
3. 「次の問題へ」で次の問題に進む。最後の問題のあとは「結果を見る」になります。
4. 全問終わると、正解数と正答率（%）が表示されます。
5. 「もう一度」で正解数が 0 に戻り、1問目からやり直せます。

解説が出ているあいだは、同じ問題の選択肢を押せません。

## ファイルの役割

| ファイル | 役割 |
| --- | --- |
| `index.html` | 見出し、スコアの置き場、問題文、選択肢、次へボタン、メッセージ。「もう一度」の置き場。`common.css` / `common.js` を相対パスで読み込む。 |
| `style.css` | 問題文、選択肢の並び、正解の緑と不正解の赤。 |
| `script.js` | 問題の配列、いまの番号、判定、解説、正答率、最初に戻す処理。 |
| `../../common/common.js` | `createScoreDisplay`、`updateScore`、`showMessage`、`clearMessage`、`createRestartButton`。 |
| `../../common/common.css` | 画面中央のレイアウト、暗い背景、スコア、メッセージ、ボタン。 |

## 読んでみる順番

1. `QUESTIONS` で、1問がどんなオブジェクトかを見る。
2. `showQuestion` と `renderChoices` で、配列の番号から画面を作る流れを追う。
3. `answer` で、`correctIndex` と比べて色とメッセージを変える箇所を確認する。
4. `finishQuiz` で、正解数から正答率を計算している行を見る。

小さく改造するなら、`QUESTIONS` の末尾にオブジェクトを1つ足してみてください。問題数が増え、最後の正答率の分母も一緒に変わります。

# 17 簡易RPG

選択肢を選んで、村から祠へ進みます。プレイヤーのHP・所持金・薬草は、1つのオブジェクトで覚えます。物語は場面ごとに分かれていて、選んだボタンで次の場面へ移ります。スライムとオオカミとは、攻撃するか逃げるかを選んで戦います。HPが0になるとゲームオーバー、星のカケラを持ち帰るとクリアです。「もう一度」で村の入り口からやり直せます。

## このゲームで学ぶ概念

- **オブジェクトで状態を持つ** … `player` は `{ hp, gold, hasHerb, openedChest }` です。数字をばらばらの変数にせず、プレイヤーの持ち物を1か所にまとめます。
- **場面のデータ** … `SCENES` は、名前をキーにしたオブジェクトです。各場面が文章と選択肢を持っています。戦闘の場面は `type: "battle"` です。
- **分岐** … 選択肢の `next` が次の場面の名前です。薬草を持っているときだけ出すボタンは、`requires` で分けます。
- **場面を切り替える関数** … `showScene` が文章とボタンを描き直します。ボタンを押したあとの進み方は `choose` にまとまっています。
- **DOMの差し替え** … 選択肢は毎回 `innerHTML` で消してから、必要なボタンだけ作ります。HPや所持金の数字は `updateScore` です。
- **関数の再利用** … ステータス、結果メッセージ、もう一度ボタンは `common.js` に任せます。

## 遊び方

1. `index.html` をブラウザで開く。村の入り口から始まります。HPは12、所持金は5です。
2. ボタンを選んで進みます。道具屋では8ゴールドで薬草を買えます。足りないときは、森の宝箱で10ゴールド手に入ります。
3. 広場ではスライムと戦います。「攻撃する」でダメージを与え、敵のHPが0になると勝ちです。倒したターンに、敵の攻撃は受けません。
4. 「逃げる」で戦闘を抜けられます。報酬はもらえず、敵のHPは次に入ったときに戻ります。
5. 薬草を持っているときだけ「薬草を使う」が出ます。HPが6回復します。戦闘中に使うと、そのあと敵の攻撃を受けます。
6. 祠のオオカミを倒すとクリアです。HPが0になるとゲームオーバーです。
7. 「もう一度」で、所持金も薬草も最初の村に戻ります。

## ファイルの役割

| ファイル | 役割 |
| --- | --- |
| `index.html` | 見出し、ステータスの置き場、物語の文章、選択肢、メッセージ。「もう一度」の置き場。`common.css` / `common.js` を相対パスで読み込む。 |
| `style.css` | ステータスの2列、文章の枠、選択肢ボタン。 |
| `script.js` | プレイヤーオブジェクト、場面データ、場面の切り替え、戦闘。 |
| `../../common/common.js` | `createScoreDisplay`、`updateScore`、`showMessage`、`clearMessage`、`createRestartButton`。 |
| `../../common/common.css` | 暗い背景、スコア、メッセージ、ボタン。 |

## 読んでみる順番

1. `createPlayer` で、プレイヤーの状態が1つのオブジェクトになっていることを見る。
2. `SCENES` で、文章と選択肢がデータとして並んでいる箇所を追う。
3. `showScene` と `choose` で、ボタンを押すと次の名前の場面へ移る流れを確認する。
4. `attack` と `applyEnemyAttack` で、勝ったときとHPが0になったときの分かれ目を見る。

小さく改造するなら、`WOLF.hp` を `8` に変えてみてください。祠の前のオオカミが、2回の攻撃で倒れます。
